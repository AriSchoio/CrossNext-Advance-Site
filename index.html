Install the firmware

CrossNext currently targets the Xteink X4 Pro (ESP32-S3). Firmware and companion content are separate downloads when a release publishes them. Back up your microSD card before changing firmware.

  1. Choose the latest stable release above and download its firmware ZIP. Check the included SHA256SUMS.txt if present.
  2. For an existing compatible installation, extract the package, copy the versioned application .bin to the microSD card, then on the reader open Settings → Device → Update firmware. Select the application image and confirm.
  3. Keep the device powered until installation and restart are complete. Do not select an image named -factory.bin in the SD updater.
  4. If provided, extract CrossNext-Resources.zip to the microSD root, merging its folders and keeping the included licences. Restart after copying.
Factory install is different. The factory image includes the bootloader and partition table and is intended for USB flashing at offset 0x0. An application-only image is not a factory image. Use only the exact image and method documented for your device; do not install X4/X3 ESP32-C3 firmware on the X4 Pro.

Read the complete installation and recovery notes before using factory flashing or updating a device with an older partition layout.

First steps & controls

CrossNext starts at Home. From there, open your recent book, browse the microSD card, enter the Library, or visit Games and Apps. The X4 Pro has two side page keys, a Power key, touch, and a capacitive Home key beneath the panel.

  • Turn pages: use the two side keys while reading. Their order can be changed in Controls settings.
  • Back: swipe from the left quarter of the screen toward the right.
  • Home: tap the capacitive Home key below the display.
  • Power: hold for about half a second to power off. A short press can be configured for sleep, page turn, refresh, or other actions.
  • Frontlight: swipe down from the top edge to adjust brightness and warmth; double-click Power to toggle it.

Some older CrossPoint/CrossPlay button instructions refer to buttons that do not exist on the X4 Pro. Use the X4 Pro-specific controls above.

Reading, library & study

The reader supports EPUB, plain text, Markdown and XTC/XTCH formats. It keeps reading position, offers chapter navigation, bookmarks, clippings and highlights, and supports configurable fonts, spacing, margins, orientation, progress display and refresh frequency.

  • Open the reader menu from the page to navigate chapters, jump by percentage, create clippings, take a screenshot, or sync reading progress.
  • Install StarDict dictionaries in /dictionaries/ for offline Define and Translate lookups.
  • Use Settings → Library to rebuild the book index after changing files or metadata on the card.
  • Custom fonts can be downloaded from device settings or installed under /.fonts/ or /fonts/. See the font guide.
  • CrossPoint-compatible sync and OPDS catalogs are configured under Settings → Connectivity. Sync requires a server and account; it is optional.

CrossNext also includes tools for flashcards, saved vocabulary, reading history, statistics, notes and productivity. Feature-specific guides are in the source repository’s app documentation.

Apps & games

The firmware extends the reader with a Home-screen shelf of games and apps. The source README documents the current shelf and changes by release. Examples include PET, Reading Quest, Notes, Habits, Flashcards, Words, Pomodoro, Calendar, Clock, Sudoku, Chess, Picross, Minesweeper, Solitaire and a Game Boy / Game Boy Color emulator.

Some apps need companion content on the microSD card. Install the matching Resources ZIP when the release provides one; the firmware displays guidance if required content is missing. CrossNext includes the Game Boy emulator, not game ROMs—add only ROMs you are authorized to use. Saves are stored beside ROM files.

For detailed app rules, controls and saved-data behavior, consult the individual app guides.

Manage files over Wi-Fi

Open File Transfer on the device and choose Join a Network, Calibre Wireless, or Create Hotspot. Then open the device’s web address in a browser to upload or download files and manage supported settings. WebDAV is also available for file-manager access.

  • To manage Wi-Fi and OPDS settings in a browser, use http://<device-ip>/settings while File Transfer is active.
  • Calibre transfers use the CrossPoint Reader device plugin. Configure its Host to the device’s IP address.
  • Do not expose the device’s file server to an untrusted network. Follow the detailed web server documentation.

How the firmware is organized

CrossNext is built on the CrossPoint reader and CrossPlay apps/games, with the FreeInk SDK providing the device-facing e-paper and hardware interfaces. Its firmware combines the reading experience, device services, and optional app/game modules into a board-specific ESP32-S3 application.

ReaderBook parsing, layout, page rendering, bookmarks, library and reading state.
Device layerDisplay, touch, buttons, battery, frontlight, clock and microSD services.
Apps & gamesIndependent shelf experiences with their own UI and local data.

For X4 Pro, the SDK selects hardware profiles and display behavior for the device. Application updates and factory images are not interchangeable: the SD updater checks the board and available slot; factory images also contain bootloader and partition data. The release ZIP is the recommended source for version-matched files and checksums.

New settings start in English; Spanish is available. Most book data and app saves stay on the microSD card. Back up your files before installation or troubleshooting.

Troubleshooting & safety

  • Required content missing: install the matching Resources ZIP to the microSD root, merge folders, and restart.
  • Update rejected: verify that you selected the application image for the X4 Pro and that the current partition slot is large enough. A microSD update does not replace the partition table.
  • Crash or boot issue: check the card for a crash report and consult the official troubleshooting guide before removing data. Back up the card first.
  • Report a problem: use the firmware repository’s issues or discussions where available, including firmware version and device model.
Firmware flashing carries a risk of data loss or an unusable device if the wrong image or method is used. Use only X4 Pro releases, keep power stable, and follow the version-specific release instructions.

04 / FAQ

Good to know

Which device does this firmware support?

The attached CrossNext source describes this release as targeting the Xteink X4 Pro (ESP32-S3). Do not use its images on the older Xteink X4/X3 or unrelated readers.

Why are there no download buttons?

This page reads published GitHub Releases and only shows direct downloads when assets are attached. A source-code repository or a firmware mentioned in documentation is not itself a published binary. Check the GitHub Releases page for current availability.

Which file should I download?

The firmware ZIP is the easiest choice because it groups the release files and checksums. For an existing installation, use the application-only image through the device’s updater. A factory image is only for the documented USB procedure. Resources ZIPs contain companion SD-card content, not firmware.

Does installing the firmware erase my books?

An SD application update is designed to update firmware, but always back up your microSD first. Resource content and personal data are separate; preserve your existing files and the hidden /.crosspoint/ folder when updating.

Where is the complete documentation?

The user guide and install guide are maintained alongside the firmware sources: User Guide, Installation, and all docs.
