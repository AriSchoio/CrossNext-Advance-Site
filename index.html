Install firmware

This CrossNext build targets the Xteink X4 Pro (ESP32-S3). Back up your microSD card before changing firmware. Download the matching firmware image from the list above.

  1. For an existing compatible installation, copy the application .bin to the microSD card.
  2. On the reader, open Settings → Device → Update firmware, select the application image, and confirm.
  3. Keep power stable until the update and restart are complete.
  4. If a release provides CrossNext-Resources.zip, extract its contents to the microSD root, merge folders, preserve licences and restart.
Do not confuse application and factory images. The SD updater expects an application-only image, not a factory image containing bootloader and partitions. Factory USB flashing is a different procedure. Use only a verified X4 Pro image; do not install X4/X3 ESP32-C3 firmware on the X4 Pro.

Read the complete installation guide ↗ for detailed image selection, checksums and limitations.

First steps & controls

CrossNext starts at Home. Open a recent book, browse the microSD, use the Library, or visit Games and Apps. The X4 Pro has two side page keys, a Power key, touch and a capacitive Home key beneath the panel.

  • Turn pages: use the two side keys while reading; their order is configurable.
  • Back: swipe from the left quarter of the screen toward the right.
  • Home: tap the capacitive key below the display.
  • Power: hold for about half a second to power off. Short-press behavior can be configured.
  • Frontlight: swipe down from the top edge to adjust brightness and warmth; double-click Power to toggle it.

Reading, study & play

The reader supports EPUB, plain text, Markdown and XTC/XTCH. It includes chapter navigation, bookmarks, highlights, configurable typography, orientation and reading progress. Open the reader menu for navigation, clippings, screenshots and optional sync.

CrossNext adds a Library, dictionary lookup, flashcards, saved vocabulary, notes, productivity tools, games and apps. Some apps need matching resource files installed on the microSD. The Game Boy emulator does not include game ROMs; add only ROMs you are authorized to use.

For detailed controls and app-specific instructions, browse the firmware documentation ↗.

File transfer over Wi-Fi

Open File Transfer on the device and choose Join a Network, Calibre Wireless, or Create Hotspot. Use the displayed device address in a browser to upload/download files. The web interface also supports WebDAV; while File Transfer is active, device settings are available at http://<device-ip>/settings.

Use the device file server only on a trusted network. See the web server documentation ↗.

How the firmware works

CrossNext combines the CrossPoint e-reader foundation, CrossPlay games and apps, and the FreeInk SDK’s hardware interfaces. The reader handles book parsing, page layout, rendering and reading state; device services provide display, input, battery, frontlight and microSD access; apps and games add separate experiences and local data.

E-paper readerBook rendering, library, reader settings and saved reading position.
Device servicesBoard-aware display, touch, buttons, power, storage and connectivity.
Apps & gamesOptional tools and entertainment; some require matching SD-card resources.

Build and hardware details are in the firmware README ↗.

Troubleshooting & safety

  • If an app reports missing content, install its matching Resources ZIP and restart.
  • If an update is rejected, confirm the image is for X4 Pro and check the release installation notes; an SD update does not rewrite the partition table.
  • Back up your card before flashing or deleting files. Preserve your books and the hidden /.crosspoint/ folder when updating resources.
  • Check for crash reports on the card and consult the official guide before attempting recovery.
Flashing the wrong image or using the wrong method can cause data loss or prevent startup. Follow the version-specific release documentation and keep power stable.

03 / FAQ

Good to know

How does the firmware list update?

The page requests the repository’s Firms/ directory from the GitHub API when opened, and refreshes it periodically while open. Newly added files appear without editing this page. GitHub Pages must already be enabled to serve the site.

Which device is supported?

This firmware build is for the Xteink X4 Pro (ESP32-S3). Do not use its binaries on older X4/X3 devices or other readers.

What if the folder cannot load?

GitHub’s public API may be temporarily unavailable or rate-limited. Use the Open Firms folder link to access downloads directly, then use Refresh or reload the site later.

Where is the full documentation?

Open the User Guide, Installation Guide or all documentation in the firmware source repo.
